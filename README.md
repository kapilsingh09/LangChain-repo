# LangChain & LangGraph Learning Repository

This repository serves as a personal workspace for learning, experimenting, and practicing with **LangChain** and **LangGraph**. It is divided into specific sub-projects, each focusing on different concepts within the broader AI and LLM ecosystem.

## 📂 Repository Structure

### 1. [`langchain/`](./langchain/)
A dedicated section for understanding core LangChain components. This includes basic and intermediate practice with:
- **Models**: Chat Models and Embedding Models.
- **Prompt Engineering**: Prompts and Templates.
- **Data Connection**: Document Loaders, Text Splitters, Retrievers, and Vector Stores.
- **Workflow**: Chains, Output Parsers, Structured Output.
- **Architecture**: Runnables and LCEL (LangChain Expression Language).

### 2. [`langgraph/`](./langgraph/)
A dedicated section focusing on agentic workflows and complex stateful applications using **LangGraph**. It includes:
- **Jupyter Notebooks** detailing key concepts like Human-in-the-Loop (HITL), chatbots, state persistence, and process interruptions.
- **Tutorials** and masterclass materials on LangGraph and LangSmith.
- A modern Python setup managed with `pyproject.toml` and `uv`.

## 🎯 Purpose

The primary goal of this repository is to build a solid foundation in developing applications using Large Language Models (LLMs) through consistent coding, testing, and practical experimentation. This is not intended to be a production application, but rather a living set of reference materials, notebooks, and scripts built throughout a learning journey.

## 🚀 Getting Started

To explore the concepts:
1. Navigate into the relevant subdirectory (`langchain` or `langgraph`).
2. Review the individual project files, scripts, and Jupyter notebooks.
3. **Dependencies**: 
   - For `langchain`, review the `requriment.txt` file.
   - For `langgraph`, the environment is managed via `pyproject.toml` (and `uv`). Use standard package managers like `pip` or `uv` to install the dependencies.
